# Wasteland Reclaimer — прототип

2D RPG в духе Fallout 2. Мир исследуется в реальном времени, а бой пошаговый:
с очками действия, прицельными ударами и критами. Есть перки на каждом
уровне, снаряжение, торговля, квесты с несколькими решениями и последствиями,
карта мира и случайные встречи. Играть можно мышью, как в Fallout, или
клавиатурой.

Весь код и тексты оригинальные. У героя, Гены, квестовых персонажей,
крысолюдов и светящегося мутанта уже есть пиксельные спрайты, остальные
персонажи, тайлы и предметы пока нарисованы процедурными плейсхолдерами.
Настоящая графика подставляется без правок кода (см. «Спрайты персонажей»).

## Установка и запуск

Нужен Python 3.9+ и `pygame-ce`. Это совместимый форк pygame, код тот же:
`import pygame`. Обычный `pygame` на Python 3.14 не ставится (нет готовой
сборки), а `pygame-ce` ставится.

```
cd game_project
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

Виртуальное окружение нужно потому, что в свежих Ubuntu/Debian ставить
пакеты в системный Python через pip запрещено, а самого `pip` может не быть.

## Управление

Играть можно мышью, как в Fallout, или клавиатурой. Буквенные клавиши
работают в любой раскладке.

| Где | Мышь | Клавиатура |
|---|---|---|
| Исследование | ЛКМ по земле — идти · по NPC — подойти и заговорить · по ящику, терминалу, двери — подойти и открыть · по предмету на земле — подобрать · по врагу — напасть. Под курсором всё, с чем можно взаимодействовать, обводится жёлтым | `WASD` идти · `Space` напасть · `E` говорить / обыскать / открыть / подобрать |
| Бой | ЛКМ по клетке — идти (путь и цена в ОД видны под курсором) · ЛКМ по врагу — атака (в ближнем бою сначала подойти) · ПКМ по врагу — прицельная атака · ЛКМ по красной бочке — выстрел (взрыв) | `WASD` шаг · `Space` атака · `Q` прицельно · `Tab` цель · `G` бросить гранату / коктейль Молотова · `R` конец хода |
| Масштаб | колёсико — ближе/дальше (4 ступени; по умолчанию камера отъехала, как в Fallout) | — |
| Окна | клик по варианту ответа, рецепту, товару, перку; [×] — закрыть | цифры `1..9`, `Tab` купить/продать, `Esc` |
| Панель внизу | кнопки «Рюкзак», «Крафт», оружие, «Карта», «Конец хода» | `I`, `C`, `F`, `M`, `R` |
| Журнал заданий | кнопка «Журнал» на панели | `J` |
| Терминалы | клик по терминалу · клик по пункту меню · при взломе — клик по слову | `E` — включить · ↑↓ Enter · Esc |
| Миникарта | клик по разведанному месту — идти туда | `M`: маленькая → большая → скрыта |
| Окно | тянуть за край — картинка масштабируется | `F11` — полный экран |
| Меню | клик по пункту | `Esc` — пауза (сохранить, загрузить, главное меню) · `F5` — быстрое сохранение · `F9` — быстрая загрузка |
| Карта мира | клик по локации — идти к ней, по той, где стоишь, — войти | `1..9`, `0` бродить, `E` войти |

При запуске — главное меню: «Продолжить» (самое свежее сохранение), «Новая
игра», «Загрузить», «Звук», «Выход». В меню «Звук» — громкость музыки и
эффектов (←→, «−»/«+» или клик по шкале), настройки запоминаются. В игре Esc открывает паузу. Сохранений шесть
слотов плюс быстрое (F5/F9); у каждого — миниатюра экрана, место, уровень,
дата и время в игре. Файлы лежат в `saves/`. В бою сохраняться нельзя.
Загрузка из случайной встречи возвращает на карту мира в то же место.

Экран — 1280×720. Окно можно растягивать: картинка масштабируется, пиксели
остаются чёткими, клики мышью пересчитываются. Мир рисуется с отъехавшей
камерой (видно примерно в 1,4 раза больше, чем раньше), колёсиком мыши
масштаб меняется; интерфейс, подписи и полоски HP при этом остаются
обычного размера.

Внизу всегда есть панель, как в Fallout: слева лог событий, справа здоровье,
опыт, в бою ход и ОД, кнопки.

В правом верхнем углу — миникарта, как автокарта в Fallout: показывает только
разведанное. Местность открывается вокруг героя по мере исследования, стены
заслоняют обзор. На ней видны герой, найденные NPC (появляются, когда
подойдёшь близко), враги в поле зрения и рамка текущего экрана. Разведанное
запоминается для каждой локации.

## Сюжет

2121 год, сорок четыре года после Великой войны, пустыня Мохаве у трассы I-15.
Дед героя, 80-летний ветеран Анкориджа, зовёт внука в городок Пятнадцатая,
чтобы открыть тайну, которую хранил с 2077 года. Дом деда разгромлен, на полу
чей-то вырванный глаз, а терминал всё ещё включён.

Полный сценарий — в [docs/story.md](docs/story.md): канон 2121 года,
большая история на три акта (15 главных городов, 5 убежищ, 3 тайные
локации — святилище Ордена Тайн, база Марипоза, станция Анклава), «Список
Марипозы» из семи ветеранов, фракции, сюжетные линии всех персонажей и
отсылки к сериалу (заговор Vault-Tec, Гуль).

Что есть в игре:
- **пролог** слайдами в стиле старого диапроектора (Esc — пропустить);
- **главный квест «Тайна деда»** в 7 стадий. Место, куда увезли деда, можно
  узнать пятью путями; попасть туда — четырьмя; всё сводится к концу главы в
  Бейкере со сводкой принятых решений;
- **город, который интересно обходить:** 13 жителей со своими историями и
  репликами вслух (салун «Последний глоток», клиника, ратуша, пост шерифа,
  палатка проповедника «Детей Единства», кладбище, доски объявлений) и два
  подземелья — **Убежище 57** (верхний ярус и запечатанный ярус Б за
  гермодверью) и **ливнёвка** под городом;
- **побочные квесты:** крысы в ливнёвке (перебить или отравить — награда:
  **самопал и патроны от шерифа**, это первый огнестрел), нижний ярус
  убежища и «Проект Панцирь» (откуда у Гены рога и почему Черепан в
  панцире), святая вода проповедника, могила пса Колбасы (жетон деда со
  Списком Марипозы), должок салуна, лом для Гены, Бензо-банда, мазь для
  Черепана, мёртвая вода на водокачке, доля Панка, посвящённая Лира, пёс
  на цепи;
- **спутник — Псина:** рыжий пёс сидит на цепи в лагере рейдеров на свалке.
  Перебейте рейдеров, подойдите к нему — герой скажет «Такая вот хуйня,
  собачка....», и пёс пойдёт следом. Он ходит за героем по всем локациям,
  в бою ходит сам сразу после героя и кусает ближайшего врага; враги бьют и
  его. Выбитый из боя пёс отползает и встаёт, когда бой кончится; вне боя
  залечивает раны. Сохраняется вместе с игрой;
- **одиннадцать терминалов RobCo** со взломом, как в Fallout 3/NV; записки,
  голозаписи и доски объявлений читаются;
- **журнал заданий** в стиле Пип-боя.

Тексты правятся без кода: `data/quests.json` (журнал), `data/dialogues.json`
(диалоги с условиями и эффектами), `data/terminals.json` (терминалы,
записки, слова для взлома), `data/slides.json` (пролог и концовки глав).

## Что есть в игре

**Бой (как в Fallout 2).** Враг замечает вас, если вы в радиусе его обзора
и между вами нет стены. Тогда все встают на клетки и ходят по очереди.
Очерёдность решает Реакция, а если напали вы, первый ход ваш.

- У вас 8 ОД на ход (лампочки на панели).
- Шанс попасть = навык − КБ цели + модификатор части тела − штраф за дальность.
- Оружие:
  - **лом** бьёт вплотную;
  - **самопал** стреляет до 7 клеток, тратит патроны и требует линии огня,
    так что стены работают как укрытия.
- Прицельные удары: голова, глаза, руки, ноги, пах. Криты калечат цель:
  ослепляют, отнимают ОД, ослабляют удар, заставляют пропустить ход.
- **Укрытия:** цель за мешками с песком, ящиками или бочками получает −25%
  к попаданию по ней — это работает и для вас.
- **Броски** (`G`): граната ранит всех в радиусе клетки, коктейль Молотова
  поджигает на три хода. Гранаты бывают у бандитов, коктейль крафтится из
  самогона, тряпки и химикатов.
- **Красные бочки** взрываются от выстрела (и от соседнего взрыва).
- **Яд и огонь** отнимают HP в начале хода; бинт и прочие лечилки снимают яд.
- **Радиация:** светящиеся мутанты, дикие гули и радтараканы облучают при
  ударе. Каждые 10 рад отъедают 1 HP от максимума (зелёная часть на полоске
  HP). Лечит антирадин (у Дока) или капельница в клинике.
- Герой в свой ход обведён зелёным, цель красным, ходящий враг жёлтым.
  Над головами бойцов видны полоски здоровья.
- Вне боя здоровье понемногу восстанавливается.

**Враги** (`data/enemies.json`):
- **крысолюды** ходят стаей с вожаком: заметил один — нападает всё логово;
- **светящийся мутант** медленный (4 ОД), облучает при ударе;
- **рейдеры** стреляют, держат дистанцию, ищут линию огня, а при малом HP
  удирают;
- **бандиты Бензо-банды** бросают гранаты, **Шрам** ещё и колет стимулятор;
- **крысолюды** в ливнёвке — с ядовитыми когтями;
- в Убежище 57: **радтараканы** (мелкие, быстрые, стаей), **дикие гули**
  (много ОД, облучают) и **турель Vault-Tec** (не двигается, стреляет
  очередью; броня везде, кроме сенсора);
- **панцирный жук** гасит бронёй 6 урона везде, кроме глаз и ног;
- **Бензо-банда и Шрам** не трогают вас, пока их не разозлить;
- в случайных встречах ещё попадаются мутанты-падальщики и крысюки.

**Живой мир.** Вне боя NPC и враги бродят в 2–3 клетках от своего места.
Враги и мирные не сходятся ближе 4 клеток. В бою, в разговоре и в открытых
окнах все замирают.

**Перки.** На каждом уровне выбор из трёх (`src/perks.py`): +ОД, бесплатные
шаги, +КБ, +крит, +урон, +стрельба, +HP, двойная добыча, лечение за
убийство, «Подвешенный язык». Последний открывает реплики [Красноречие] и
даёт скидку у торговца.

**Квесты и последствия** (`data/dialogues.json`):
- **Лом для Гены.** Принести 3 лома или уболтать Гену [Красноречие].
- **Заначка Гены.** Спрятана за стеной в его лагере. Украсть можно, но Гена
  узнает и перестанет торговать и давать работу. Помириться можно только
  [Красноречием].
- **Бензо-банда на заправке.** Главарь Шрам сначала заговорит. Варианты:
  - перебить банду;
  - уговорить уйти [Красноречие] или запугать [Уровень 4+];
  - откупиться за 50 крышек.

  Гена платит по-разному в зависимости от исхода. Склад на заправке заперт:
  отмычка открывает его тихо, лом громко, и банда услышит.

**Торговля и рюкзак.** Валюта — крышки. У Гены можно купить патроны, бинты,
тоник, отмычки и куртку из покрышек (+10 КБ) и продать лишнее за полцены.

Рюкзак (`I` или кнопка на панели) — одно окно в три зоны:
- **слева** — слоты снаряжения (голова, тело, оружие) и характеристики;
- **в центре** — вкладки (Оружие, Броня, Лечение, Ресурсы, Разное) и сетка ячеек
  с иконками и количеством;
- **справа** — карточка предмета: описание, свойства (лечение, урон, КБ, в каких
  рецептах нужен), цена и кнопка действия.

Клик по ячейке выбирает предмет, двойной клик или `E` применяет его
(лечилки, взять оружие в руки, надеть или снять броню). В бою применение
стоит 4 ОД, а переодеваться нельзя.

**Анимации боя.** Герой бьёт ломом и стреляет (кадры дорисованы
`tools/make_hero_anims.py`). Все остальные атакуют рывком со следом когтей
или вскидывают оружие и стреляют. Все вздрагивают от попаданий и
уворачиваются от промахов — эти кадры игра строит сама из стоячего кадра
персонажа (`src/loader.py`). Кровь (`src/gore.py`): от удара — брызги, от
выстрела — кровь и кусочки плоти, от крита или смертельного выстрела —
ошмётки с уровня головы. Капли падают и остаются пятнами на полу локации.

**Звук.** Выстрел, удар ломом, попадание по телу (вместе с вздрагиванием
цели), фоновая музыка по кругу. Звук слева от центра экрана громче в левом
ухе. Исходники — в `sounds/`, игровые версии готовит скрипт:

```
.venv/bin/python tools/prepare_sounds.py   # нужен ffmpeg -> assets/sounds/, assets/music/
```

Он обрезает тишину в начале и конце (чтобы звук совпадал с ударом),
выравнивает громкость и сжимает музыку в OGG. Какой файл каким звуком
становится — таблица `SOUNDS` в скрипте. Исходный WAV музыки в git не
кладётся, только сжатый OGG.

**Выстрелы** — пуля летит от дула к цели с коротким светящимся хвостом;
цель вздрагивает, когда пуля долетает. При промахе пуля уходит мимо.

**Обыск и тела.** Ящики, шкафы, сейфы и тела открываются окном в две
половины, как в Fallout: слева рюкзак, справа содержимое. Клик по ячейке
переносит всю стопку, правый клик — одну штуку, «Взять всё» (R) — всё сразу.
Вещи можно и класть: в любой контейнер, в том числе пустой. Убитые враги
остаются лежать, их добыча — на теле. Чужое (заначка Гены, склад банды)
считается кражей в момент, когда что-то взял; банда заметит, только если
видит вора.

**Снаряжение.** Броня надевается в слоты «Голова» и «Тело», надетое отмечено
галочкой. Новая броня сама надевается, если слот пуст. Бонусы указаны в
`data/items.json`: `armor_ac` (КБ), `ap` (ОД), `guns` (стрельба).

| Предмет | Слот | Бонус | Где взять |
|---|---|---|---|
| куртка из покрышек | тело | +10 КБ | Гена |
| бронежилет из дорожных знаков | тело | +20 КБ, −1 ОД | сейф на заправке |
| каска строителя | голова | +5 КБ | Гена |
| мотошлем | голова | +8 КБ, −5% стрельбы | вожак крысолюдов |

На спрайте героя надетое пока не видно.

**Город у трассы** — стартовая карта 96×64 клетки, собранная из набора
«wasteland town» и своих объектов: около 90 мест для обыска и 11 зданий. У
зданий все четыре стены; у домов к северу от улицы двери в южной стене, к
югу от улицы — в северной (двери смотрят на улицу). Районы:
- **запад** — въезд с трассы, остановка, отсюда старт;
- **северо-запад** — жилой квартал: дом деда, дома жителей (Марта), дворы;
- **салун «Последний глоток»** — Мо «Ведро» за стойкой, пьяница Лен;
- **рынок** — лавка Гены, прилавки, палатка брата Сайласа с бочкой
  «святой воды», доска объявлений;
- **водокачка** на северо-востоке — баки, контора, светящиеся мутанты;
- **юг у дороги** — дом Черепана без крыши, пост шерифа Брэддока, клиника
  Дока Миры, ратуша Смотрительницы Ады;
- **юго-запад** — руины склада с люком в **ливнёвку** (под городом —
  тоннели и логово крысолюдов) и кладбище с могилой пса Колбасы;
- **столовая гора** с дверью-шестернёй **Убежища 57**, часовой Дейл;
- **сквер** — высохшие деревья, скамейки, панцирный жук;
- **свалка** на юго-востоке — горы хлама, контора, лагерь рейдеров, пёс на
  цепи, лачуга Панка-одиночки.

Жители иногда говорят что-нибудь вслух, когда проходишь рядом
(`data/barks.json`).

**Черепан** живёт в кирпичном доме к югу от улицы. Просит 2 химиката на мазь
для панциря и платит тоником.

Квестовых персонажей надо поискать: Блонди прячется за баком у водокачки,
Панк-одиночка сидит в лачуге на свалке. Гена подскажет, где их искать
(«Не видел тут других людей?»). Выходы из города — на западе и на юге.
Высокие объекты (стены, шкафы, палатки, баки) закрывают персонажей за собой
и перекрывают линию огня в бою.

**Карта мира.** Выход из локации отмечен стрелками `>>>` на краю карты.
В пути бывают случайные встречи: крысюки, мутанты, рейдеры, жук, брошенная
тележка каравана и почтовый робот.

## Структура проекта

## Набор «wasteland town» и карта города

Исходники — пять страниц 768×768 в папке `wasteland town/`. Нарезка:

```
.venv/bin/python tools/slice_town.py    # -> assets/town/ground/, assets/town/props/
.venv/bin/python tools/build_town.py    # -> data/maps/town.json
```

- Страница 1 режется по координатам: клетки земли 48×48 (асфальт,
  разметка, гравий), стены, заборы, дома, пятна земли. Боковых стен
  (с севера на юг) в наборе нет — скрипт собирает их из фасадов: сверху
  верх стены, у южного конца торец. Куски стыкуются в сплошную стену.
- Страницы 2–5 режутся автоматически по прозрачности: мебель, хлам, бочки,
  палатки, знаки, трава. Получается 341 объект.
- В `data/props.json` у каждого объекта: картинка, масштаб (набор нарисован
  в разных масштабах), пятно на земле в клетках, проходимость, закрывает ли
  обзор, что можно найти при обыске. Там же таблицы добычи.
- Карта города собирается скриптом по районам: дороги, здания, дворы, потом
  объекты и мелочи. Скрипт не ставит объект, если тот отрезал бы проход,
  и проверяет, что все NPC, враги, предметы и выходы достижимы. Случайность
  фиксирована, так что карта каждый раз одна и та же. Чтобы поменять город,
  правьте районы в `tools/build_town.py` и перезапускайте его.
- Подземелья (`tools/build_underground.py`) строятся так же, но из «скалы»:
  код земли `x` — толща стены, над полом у неё рисуется лицевая стена (стиль
  карты: `vault` — стальные панели с полосой Vault-Tec, `drain` — бетонные
  кольца с тиной). Полы: `m` — стальные плиты, `w` — мокрый бетон. Под
  землёй темно — светло только вокруг героя (`dark` в карте).
- Переходы между картами — порталы (`portals` в карте: клетки, куда ведут,
  где появиться). Гермодвери (`gates`) открываются ключ-картой или флагом
  с терминала.
- Земля: асфальт и гравий — из набора, а обычная земля генерируется
  бесшовным пиксельным шумом в цветах набора, с пятнами светлее и темнее.
- Здание в генераторе: `building(x, y, ширина, высота, стиль, south=..., west=..., east=...)`,
  стили `brick`, `concrete`, `metal`, `planks`; ширина чётная (фасады по 2 клетки).

## Сборка exe

Игра собирается в один исполняемый файл PyInstaller'ом (`WastelandReclaimer.spec`).
В файл попадают только `assets/` и `data/`, шрифты — внутри, так что
кириллица есть и там, где DejaVu не установлен. Сохранения игра пишет в
`saves/` рядом с exe, ошибки — в `crash.log` там же.

**Windows (.exe)** собирается на GitHub: вкладка **Actions → «Сборка exe для
Windows» → Run workflow**. Через несколько минут внизу страницы запуска, в
Artifacts, появится `WastelandReclaimer-windows` с exe внутри. Если поставить
тег (`git tag v0.1 && git push --tags`), exe ещё и прикрепится к релизу.
Собрать .exe на Linux нельзя: PyInstaller собирает только под ту систему, на
которой запущен.

**Linux** — локально:

```
.venv/bin/pip install pyinstaller
.venv/bin/pyinstaller WastelandReclaimer.spec     # -> dist/WastelandReclaimer
dist/WastelandReclaimer --smoke                   # проверка: город, кадры, сохранение
```

## Спрайты персонажей

Исходные листы лежат в `npc/`. Формат: 192×192, сетка 4×4 кадра по 48×48.
Строки: 0 — спиной (вверх), 1 — вправо, 2 — лицом (вниз), 3 — влево.
Столбцы — фазы шага.

Особые листы описаны в `SPECIAL` в `tools/slice_sprites.py`: пёс `npc/dog.png`
(512×512, клетки 128×128, строки вниз/вправо/вверх/влево) режется в
`assets/sprites/dog/` уже в игровом размере (файл-метка `native` — без
увеличения).

Часть врагов нарисована поверх уже нарезанных персонажей —
`tools/make_variants.py` (после нарезки; `preview` — лист-превью):
рейдер — из Панка (красный ирокез, бандана, наплечник с шипами), бандит
Бензо-банды — из героя (противогаз, промасленная кожанка с жёлтой полосой),
Шрам — из Панка (бритый, шрам через лицо, светящийся глаз, два наплечника),
панцирный жук — из пса (хитин, надкрылья, усики, жвалы, лишние лапы).

Нарезка в кадры игры:

```
.venv/bin/python tools/slice_sprites.py
```

Кадры попадают в `assets/sprites/<id>/{down,left,right,up}/0..3.png`, игра
увеличивает их в 2 раза без сглаживания. Кто есть кто — в словаре `SHEETS`
в начале скрипта:

| Лист | id | Кто |
|---|---|---|
| hero_01 | player | главный герой |
| npc_02_office_mutant | gena | Ржавый Гена |
| npc_03_blondie | blondie | Блонди (квестовый) |
| npc_04_raider | loner | Панк-одиночка (квестовый) |
| npc_05_ratman | ratman | крысолюд (враг, ходит стаей) |
| npc_05_ratman_boss | ratman_boss | вожак крысолюдов |
| npc_06_mutant | rad_mutant | светящийся мутант (медленный) |
| npc_07_mutant_turtle | turtle | Черепан, мирный мутант-черепаха (квест) |

**Боевые анимации героя** — удар ломом и выстрел по 3 кадра на каждую
сторону — дорисованы поверх нарезанных кадров скриптом:

```
.venv/bin/python tools/make_hero_anims.py   # -> assets/sprites/player/melee/, shoot/
```

Если перерисовать героя (новый `hero_01.png`), скрипт нужно перезапустить
после `slice_sprites.py`. Реакции на попадание (отброс и красная вспышка) и
уворот при промахе врага игра строит сама для всех персонажей из их стоячего
кадра. Свои кадры можно положить в `assets/sprites/<id>/melee|shoot/<сторона>/`.

Новый персонаж: положить лист в `npc/`, добавить строку в `SHEETS`,
перезапустить скрипт. Враги описываются в `data/enemies.json`, на карте их
обозначает буква из `ENEMY_TILES` в `src/tilemap.py`: `k` — крысолюд,
`K` — вожак, `z` — светящийся мутант, `m` — мутант-падальщик, `r` — крысюк,
`R` — рейдер, `B` — жук, `g` — бандит, `S` — Шрам. Это для текстовых карт;
в городе враги расставляются в `tools/build_town.py`.

У остальных (рейдеры, бандиты, Шрам, жук, крысюки, робот) пока
плейсхолдеры. Для них подходит та же схема: `assets/sprites/<id>/`.
Иконки предметов — `assets/items/*.png`. Тайлы и фон текстовых карт (заправка,
встречи) — `assets/tiles/*.png`, `assets/bg/layer0..2.png`.

Бесплатные источники:
- Персонаж: **Animated Pixel Adventurer** (rvros, можно скачать за 0) —
  https://rvros.itch.io/animated-pixel-hero
- Тайлы (CC0): **Pixel Art Wasteland** — https://opengameart.org/content/pixel-art-wasteland
- Пропсы: **Post Apocalyptic Toxic Wasteland** —
  https://0-mem0ry.itch.io/post-apocalyptic-toxic-wasteland-free/purchase
- Фон одним слоем: **Free Pixel-art background, desert** —
  https://blank-canvas.itch.io/parallax-pixel-art-background-desert
- Многослойный фон (платный, $2.45, нужна атрибуция): **Desert Dune Valley
  Parallax Background** — https://dlou-saiyan.itch.io/desert-dune-valley-parallax-background-2d-pixel-art-desert-environment

У каждого пака своя лицензия, читай её на странице пака, прежде чем
выкладывать игру.

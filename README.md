# Wasteland Reclaimer — прототип

2D RPG в духе Fallout 2. Мир исследуется в реальном времени, а бой пошаговый:
с очками действия, прицельными ударами и критами. Есть навыки и перки
(уровень даётся небыстро), снаряжение, торговля, квесты с несколькими
решениями и последствиями, карта мира и случайные встречи. Играть можно мышью, как в Fallout, или
клавиатурой.

Весь код и тексты оригинальные. У героя, Гены, квестовых персонажей,
крысолюдов и светящегося мутанта уже есть пиксельные спрайты, остальные
персонажи, тайлы и предметы пока нарисованы процедурными плейсхолдерами.
Настоящая графика подставляется без правок кода (см. «Спрайты персонажей»).

## Установка и запуск

Нужен Python 3.9+ и `pygame-ce`. Это совместимый форк pygame, код тот же:
`import pygame`. Обычный `pygame` на Python 3.14 не ставится (нет готовой
сборки), а `pygame-ce` ставится.

```
cd game_project
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

Виртуальное окружение нужно потому, что в свежих Ubuntu/Debian ставить
пакеты в системный Python через pip запрещено, а самого `pip` может не быть.

## Управление

Играть можно мышью, как в Fallout, или клавиатурой. Буквенные клавиши
работают в любой раскладке.

| Где | Мышь | Клавиатура |
|---|---|---|
| Исследование | ЛКМ по земле — идти · по NPC — подойти и заговорить · по ящику, терминалу, двери — подойти и открыть · по предмету на земле — подобрать · по врагу — напасть · **Shift + ЛКМ по жителю — напасть на него**. Под курсором всё, с чем можно взаимодействовать, обводится жёлтым | `WASD` идти · `Space` напасть · `E` говорить / обыскать / открыть / подобрать · `Shift+E` напасть на жителя рядом |
| Бой | ЛКМ по клетке — идти (путь и цена в ОД видны под курсором) · ЛКМ по врагу — атака (в ближнем бою сначала подойти) · ПКМ по врагу — прицельная атака · ЛКМ по красной бочке — выстрел (взрыв) | `WASD` шаг · `Space` атака · `Q` прицельно · `Tab` цель · `G` бросить гранату / коктейль Молотова · `R` конец хода |
| Масштаб | колёсико — ближе/дальше (4 ступени; по умолчанию камера отъехала, как в Fallout) | — |
| Окна | клик по варианту ответа, рецепту, товару, перку; [×] — закрыть | цифры `1..9`, `Tab` купить/продать, `Esc` |
| Панель внизу | кнопки «Рюкзак», «Крафт», оружие, «Карта», «Конец хода» | `I`, `C`, `F`, `M`, `R` |
| Журнал заданий | кнопка «Журнал» на панели | `J` |
| Терминалы | клик по терминалу · клик по пункту меню · при взломе — клик по слову | `E` — включить · ↑↓ Enter · Esc |
| Миникарта | клик по разведанному месту — идти туда | `M`: маленькая → большая → скрыта |
| Окно | тянуть за край — картинка масштабируется | `F11` — полный экран |
| Меню | клик по пункту | `Esc` — пауза (сохранить, загрузить, главное меню) · `F5` — быстрое сохранение · `F9` — быстрая загрузка |
| Карта мира | клик по локации — идти к ней, по той, где стоишь, — войти | `1..9`, `0` бродить, `E` войти |

При запуске — главное меню: «Продолжить» (самое свежее сохранение), «Новая
игра», «Загрузить», «Звук», «Выход». В меню «Звук» — громкость музыки и
эффектов (←→, «−»/«+» или клик по шкале), настройки запоминаются. В игре Esc открывает паузу. Сохранений шесть
слотов плюс быстрое (F5/F9); у каждого — миниатюра экрана, место, уровень,
дата и время в игре. Файлы лежат в `saves/`. В бою сохраняться нельзя.
Загрузка из случайной встречи возвращает на карту мира в то же место.

Экран — 1280×720. Окно можно растягивать: картинка масштабируется, пиксели
остаются чёткими, клики мышью пересчитываются. Мир рисуется с отъехавшей
камерой (видно примерно в 1,4 раза больше, чем раньше), колёсиком мыши
масштаб меняется; интерфейс, подписи и полоски HP при этом остаются
обычного размера.

Внизу всегда есть панель, как в Fallout: слева лог событий, справа здоровье,
опыт, в бою ход и ОД, кнопки.

В правом верхнем углу — миникарта, как автокарта в Fallout: показывает только
разведанное. Местность открывается вокруг героя по мере исследования, стены
заслоняют обзор. На ней видны герой, найденные NPC (появляются, когда
подойдёшь близко), враги в поле зрения и рамка текущего экрана. Разведанное
запоминается для каждой локации.

идёт следом, переходит с героем между локациями, в бою ходит сам (стрелки держат дистанцию). E рядом —
поговорить или отпустить домой: житель возвращается на своё место.
План третьего акта — docs/story.md, раздел 17. **Барстоу** —
изометрический.

**В Барстоу играешь за наёмника Дэкса.** Дэкс — бывший охранник караванов
Хаба — сидит у въезда в Пятнадцатую: караван Розы (вода и фильтры для
водокачки, товар Гены) застрял в Барстоу, город заняли дикие гули. Квест
«Контракт на Барстоу»: нанять Дэкса (100 крышек; 50, если за героя поручился
шериф; бесплатно с [Красноречием]) — слайды «Тем временем…» — и управление
переходит к Дэксу: у него своё здоровье (120), 4-й уровень, перк «Верная рука»,
автомат и дробовик, стимуляторы; на панели — «Дэкс · Барстоу». Герой ждёт там,
где стоял. Уйти с трассы Дэкс согласен, только когда Роза расплатилась за
зачистку; тогда «Дорога домой», караван приходит в Пятнадцатую (Роза торгует
у рынка), управление — снова герою, Дэкс у въезда отдаёт долю. Поэтому в
изометрии и человек другой (выживший из набора), и с оружием в руках.
Код — `src/game/merc.py`; сохраняются оба персонажа.

**Экшен-режим.** Барстоу за Дэкса — не пошаговый бой, а стрельба в реальном
времени (`src/action.py`, `"action": true` у локации в `data/locations.json`):

| Что | Как |
|---|---|
| бежать | `WASD` (по экрану) |
| целиться / стрелять | мышь / зажать ЛКМ (по жителю, ящику, двери — клик как обычно) |
| рывок | ПКМ или `Shift` — три клетки туда, куда бежишь (стоишь — к прицелу), раз в 2.5 с |
| сменить ствол | `Q`, `1` — автомат, `2` — дробовик |
| перезарядить | `R` (или само, когда магазин пуст) |

Аркада в духе Crimsonland: попадание — гуль вспыхивает и вздрагивает, из ствола
летят гильзы, дробовик трясёт экран; убитый гуль падает и отлетает по направлению
выстрела. С убитых падают бонусы (лежат 12 с, к концу мигают): **аптечка** (+40 HP),
**ярость** (скорострельность ×2 на 8 с), **бронебойные** (пуля прошивает до трёх гулей,
10 с), **граната** (взрыв вокруг Дэкса). Сверху — счёт убитых и серия: убийства
без паузы больше 2.5 с — «СЕРИЯ ×5», «×10»…

- **Автомат** — очередь, 30 патронов, перезарядка 3 с. **Дробовик** — 8
  выстрелов веером дроби (отбрасывает гулей), перезарядка 5 с: патроны
  закладываются по одному, это видно на полоске над Дэксом. Патроны бесконечные.
- Урон постоянный: пуля автомата — 10, дробина — 5 (их 7 в заряде). Гули
  падают от одного и того же числа пуль: **бегун — 2, обычный — 3,
  светящийся — 5**; дробовик вплотную валит обычного гуля одним выстрелом.
- Гули бродят по городу; заметив Дэкса, бегут к нему кратчайшим путём в обход
  стен и бьют вблизи. Обычные — медленнее Дэкса, бегуны — быстрее, светящиеся
  — медленные, но облучают.
- **Толпы в домах**: подошёл к двери отеля, магазина, кинотеатра, ангара —
  изнутри вываливаются 12–20 гулей (экран вздрагивает) и бегут следом. Можно
  убежать и отстреливаться. Район считается зачищенным, когда вышли все толпы
  и никого не осталось.
- Пока за Дэксом гонятся, сохраняться нельзя.
- Опыта в экшене нет: Дэкс работает по контракту (награда — крышки и караван).

**Барстоу** (на карту мира не выведен — туда ходит Дэкс) — город из
четырёх локаций, связанных переходами (жёлтые ромбы на земле, у курсора —
«Переход: …»):
- **трасса** — мотель «Сансет» с неоном (контора с терминалом, номера 4–7;
  номер 7 заперт — нужна отмычка), стоянка караванщиков: **Роза** торгует,
  рассказывает слухи и даёт работу; выходы на карту мира на запад и восток;
- **депо** — сортировочная: пути со шпалами, платформы с грузами,
  водонапорная башня, семафоры, контора депо (терминал: состав West Tek на
  склад «Бейкер-7», взлом сейфа), ангар без крыши; стая гулей и светящийся;
- **центр** — перекрёсток, отель «HOTEL», магазин «D-MART», кинотеатр
  «Мираж» с неоновой вывеской, руины квартала; гули на улицах и в зданиях;
- **святилище Ордена Тайн** — тайная дверь за экраном кинотеатра пускает
  только с брошью Ордена (её отдаёт Мо в Пятнадцатой).

Суть Барстоу — **зачистка районов**: когда в депо или в центре не остаётся
гулей, район отмечается («Район зачищен», +50 опыта), это двигает квест Розы
«Зачистка Барстоу»; за оба района — 150 крышек, патроны и опыт. Гули —
дикие гули Fallout: обычные, бегуны (много ОД) и светящиеся (облучают).

```
.venv/bin/python main.py --iso              # сразу за Дэкса в изометрический Барстоу
.venv/bin/python tools/slice_iso.py         # персонажи из набора -> assets/iso/chars/
.venv/bin/python tools/build_barstow.py     # карты Барстоу -> data/maps/barstow*.json (тайлы копирует сам)
```

- Мир остался прежней сеткой клеток (пути, бой, столкновения, квесты,
  сохранения — без изменений); меняется только проекция: клетка — ромб
  128×64 (`src/iso.py`, камера `Camera.p/inv`). Изометрическая карта —
  `src/isomap.py`, помощники генераторов — `tools/isokit.py` (здания со
  стенами на рёбрах клеток, дороги, тротуары, машины, заборы, вывески,
  рельсы, неон).
- Когда герой входит в здание, крыша (плиты с парапетом и надписью краской)
  тает, а передние стены становятся полупрозрачными.
- Герой — выживший из набора, 8 направлений; гули — городские зомби набора.
  Клавиши WASD двигают по экрану, мышь — как раньше.
- Набор тёмный (ночной город) — тайлы и персонажи при загрузке осветляются,
  у персонажей тонкий контур; земля пустоши — тёмная земля набора,
  перекрашенная в песок (`@dust` в `tools/slice_iso.py`).
- Пока нет: изометрических спрайтов жителей (Роза — прежний спрайт) и мебели
  для интерьеров (набор Zombie Interior). Сам герой в изометрию пока не
  ходит — для него нужен свой спрайт в 8 направлениях (Character Creator).

## Сюжет

2121 год, сорок четыре года после Великой войны, пустыня Мохаве у трассы I-15.
Дед героя, 80-летний ветеран Анкориджа, зовёт внука в городок Пятнадцатая,
чтобы открыть тайну, которую хранил с 2077 года. Дом деда разгромлен, на полу
чей-то вырванный глаз, а терминал всё ещё включён.

Полный сценарий — в [docs/story.md](docs/story.md): канон 2121 года,
большая история на три акта (15 главных городов, 5 убежищ, 3 тайные
локации — святилище Ордена Тайн, база Марипоза, станция Анклава), «Список
Марипозы» из семи ветеранов, фракции, сюжетные линии всех персонажей и
отсылки к сериалу (заговор Vault-Tec, Гуль).

Что есть в игре:
- **пролог** слайдами в стиле старого диапроектора (Esc — пропустить);
- **главный квест «Тайна деда»**. Место, куда увезли деда, можно
  узнать пятью путями; попасть туда — четырьмя (с караваном Гены, с Лирой,
  с Панком, за братом Сайласом или одному);
- **вторая глава — Бейкер** (см. ниже): деда можно выкрасть, выменять или
  отбить штурмом, и выбранный путь ведёт в свою ветку сюжета. Глава
  заканчивается на складе «Бейкер-7» слайдами со сводкой решений;
- **город, который интересно обходить:** 13 жителей со своими историями и
  репликами вслух (салун «Последний глоток», клиника, ратуша, пост шерифа,
  палатка проповедника «Детей Единства», кладбище, доски объявлений) и два
  подземелья — **Убежище 57** (верхний ярус и запечатанный ярус Б за
  гермодверью) и **ливнёвка** под городом;
- **побочные квесты:** крысы в ливнёвке (перебить или отравить — награда:
  **самопал и патроны от шерифа**, это первый огнестрел), нижний ярус
  убежища и «Проект Панцирь» (откуда у Гены рога и почему Черепан в
  панцире), святая вода проповедника, могила пса Колбасы (жетон деда со
  Списком Марипозы), должок салуна, лом для Гены, Бензо-банда, мазь для
  Черепана, мёртвая вода на водокачке, доля Панка, посвящённая Лира, пёс
  на цепи;
- **спутник — Псина:** рыжий пёс сидит на цепи в лагере рейдеров на свалке.
  Перебейте рейдеров, подойдите к нему — герой скажет «Такая вот хуйня,
  собачка....», и пёс пойдёт следом. Он ходит за героем по всем локациям,
  в бою ходит сам сразу после героя и кусает ближайшего врага; враги бьют и
  его. Выбитый из боя пёс отползает и встаёт, когда бой кончится; вне боя
  залечивает раны. Сохраняется вместе с игрой;
- **одиннадцать терминалов RobCo** со взломом, как в Fallout 3/NV; записки,
  голозаписи и доски объявлений читаются;
- **журнал заданий** в стиле Пип-боя.

Тексты правятся без кода: `data/quests.json` (журнал), `data/dialogues.json`
(диалоги с условиями и эффектами), `data/terminals.json` (терминалы,
записки, слова для взлома), `data/slides.json` (пролог и концовки глав).

## Что есть в игре

**Бой (как в Fallout 2).** Враг замечает вас, если вы в радиусе его обзора
и между вами нет стены. Тогда все встают на клетки и ходят по очереди.
Очерёдность решает Реакция, а если напали вы, первый ход ваш.

- У вас 8 ОД на ход (лампочки на панели).
- Шанс попасть = навык − КБ цели + модификатор части тела − штраф за дальность.
- Оружие:
  - **лом** бьёт вплотную;
  - **самопал** стреляет до 7 клеток, тратит патроны и требует линии огня,
    так что стены работают как укрытия;
  - **10-мм пистолет** (сейф деда) и **охотничья винтовка** (Дэкс) — точнее
    и дальше;
  - **дробовик** — 16 урона, до 5 клеток, вплотную +20% к попаданию; дальше
    второй клетки дробь рассеивается (−18% урона за клетку). Патроны — дробь.
    Где взять: трейлер Мэйбл, бродячий торговец;
  - **автомат** — очередь из трёх пуль по 7 урона за 6 ОД. У каждой пули свой
    бросок, отдача −12% за пулю, броня гасит каждую пулю отдельно (против
    роботов плохо), прицелиться нельзя, патроны тают. Где взять: шкафчик
    сержанта на складе «Бейкер-7», торговец, шагающая броня.
- Прицельные удары: голова, глаза, руки, ноги, пах. Криты калечат цель:
  ослепляют, отнимают ОД, ослабляют удар, заставляют пропустить ход.
- **Укрытия:** цель за мешками с песком, ящиками или бочками получает −25%
  к попаданию по ней — это работает и для вас.
- **Броски** (`G`): граната ранит всех в радиусе клетки, коктейль Молотова
  поджигает на три хода. Гранаты бывают у бандитов, коктейль крафтится из
  самогона, тряпки и химикатов.
- **Красные бочки** взрываются от выстрела (и от соседнего взрыва).
- **Яд и огонь** отнимают HP в начале хода; бинт и прочие лечилки снимают яд.
- **Радиация:** светящиеся мутанты, дикие гули и радтараканы облучают при
  ударе. Каждые 10 рад отъедают 1 HP от максимума (зелёная часть на полоске
  HP). Лечит антирадин (у Дока) или капельница в клинике.
- Герой в свой ход обведён зелёным, цель красным, ходящий враг жёлтым.
  Над головами бойцов видны полоски здоровья.
- Вне боя здоровье понемногу восстанавливается.

**Враги** (`data/enemies.json`):
- **крысолюды** ходят стаей с вожаком: заметил один — нападает всё логово;
- **светящийся мутант** медленный (4 ОД), облучает при ударе;
- **рейдеры** стреляют, держат дистанцию, ищут линию огня, а при малом HP
  удирают;
- **бандиты Бензо-банды** бросают гранаты, **Шрам** ещё и колет стимулятор;
- **крысолюды** в ливнёвке — с ядовитыми когтями;
- в Убежище 57: **радтараканы** (мелкие, быстрые, стаей), **дикие гули**
  (много ОД, облучают) и **турель Vault-Tec** (не двигается, стреляет
  очередью; броня везде, кроме сенсора);
- **панцирный жук** гасит бронёй 6 урона везде, кроме глаз и ног;
- **Бензо-банда и Шрам** не трогают вас, пока их не разозлить;
- **крысюки** — мелкие ящероподобные твари в руинах над ливнёвкой и в
  случайных встречах; ещё там попадаются мутанты-падальщики;
- **шагоход Анклава** (`mech`) уже заведён, но пока не расставлен: это охрана
  станции Анклава «Посейдон-7» из следующих глав. Броня гасит 8 урона везде,
  кроме открытой кабины пилота (прицельно — «глаза»), бьёт из пушки, бросает
  гранаты.

**Город помнит преступления** (`src/game/crime.py`). Напасть можно на любого
жителя (Shift + клик). Тогда бойцы города берутся за оружие: в Пятнадцатой
шериф, Дейл, Мо, Блонди, Дэкс; в Бейкере Ник и Холлис; в миссии — весь культ.
Мирные разбегаются и с убийцей больше не разговаривают. Это запоминается:
при следующем приходе и после загрузки стража снова стреляет, убитые
остаются мёртвыми. На шум боя сбегаются все враждебные той же фракции в
радиусе 20 клеток, даже из-за стены.

**Живой мир.** Вне боя NPC и враги бродят в 2–3 клетках от своего места.
Враги и мирные не сходятся ближе 4 клеток. В бою, в разговоре и в открытых
окнах все замирают.

**Перки и навыки** — см. «Прокачка и баланс». «Подвешенный язык» открывает
реплики [Красноречие] (как и навык Красноречие 60) и даёт скидку у торговца.

**Квесты и последствия** (`data/dialogues.json`):
- **Лом для Гены.** Принести 3 лома или уболтать Гену [Красноречие].
- **Заначка Гены.** Спрятана за стеной в его лагере. Украсть можно, но Гена
  узнает и перестанет торговать и давать работу. Помириться можно только
  [Красноречием].
- **Бензо-банда на заправке.** Главарь Шрам сначала заговорит. Варианты:
  - перебить банду;
  - уговорить уйти [Красноречие] или запугать [Уровень 4+];
  - откупиться за 50 крышек.

  Гена платит по-разному в зависимости от исхода. Склад на заправке заперт:
  отмычка открывает его тихо, лом громко, и банда услышит.

**Торговля и рюкзак.** Валюта — крышки. У Гены можно купить патроны, бинты,
тоник, отмычки и куртку из покрышек (+10 КБ) и продать лишнее за полцены.

Рюкзак (`I` или кнопка на панели) — одно окно в три зоны:
- **слева** — слоты снаряжения (голова, тело, оружие) и характеристики;
- **в центре** — вкладки (Оружие, Броня, Лечение, Ресурсы, Разное) и сетка ячеек
  с иконками и количеством;
- **справа** — карточка предмета: описание, свойства (лечение, урон, КБ, в каких
  рецептах нужен), цена и кнопка действия.

Клик по ячейке выбирает предмет, двойной клик или `E` применяет его
(лечилки, взять оружие в руки, надеть или снять броню). В бою применение
стоит 4 ОД, а переодеваться нельзя.

**Анимации боя.** Герой бьёт ломом и стреляет (кадры дорисованы
`tools/make_hero_anims.py`). Все остальные атакуют рывком со следом когтей
или вскидывают оружие и стреляют. Все вздрагивают от попаданий и
уворачиваются от промахов — эти кадры игра строит сама из стоячего кадра
персонажа (`src/loader.py`). Кровь (`src/gore.py`): от удара — брызги, от
выстрела — кровь и кусочки плоти, от крита или смертельного выстрела —
ошмётки с уровня головы. Капли падают и остаются пятнами на полу локации.

**Звук.** Выстрел, удар ломом, попадание по телу (вместе с вздрагиванием
цели), фоновая музыка по кругу. Звук слева от центра экрана громче в левом
ухе. Исходники — в `sounds/`, игровые версии готовит скрипт:

```
.venv/bin/python tools/prepare_sounds.py   # нужен ffmpeg -> assets/sounds/, assets/music/
```

**Музыка и звуки Fallout 2 — отдельной папкой, для личного пользования.**
Музыка и звуки взяты из Fallout 2 (© Bethesda/Interplay, музыка — Марк
Морган) и в репозиторий **не кладутся**. Они лежат в отдельной папке
`fallout2_sounds` (музыка `music/*.ogg`, звуки `sfx/*.wav`, около 20 МБ).

После клонирования репозитория:

1. Положите папку `fallout2_sounds` **рядом** с папкой `game_project`
   (или внутрь неё):
   ```
   wasteland_reclaimer/
     game_project/        ← клон репозитория
     fallout2_sounds/     ← папка со звуками (кладётся вручную)
       music/  sfx/  README.txt
   ```
   Можно и в любое другое место — тогда укажите путь в переменной
   окружения `FALLOUT2_SOUNDS`.
2. Запустите игру — она найдёт папку сама. В меню «Звук» внизу написано,
   откуда играет звук.

Без папки игра тоже работает — играют свои звуки (`assets/sounds`,
`assets/music`). В exe папка не попадает. Если папки нет, но на компьютере
установлен Fallout 2 и есть ffmpeg, игра соберёт такие же звуки сама из его
копии в `f2cache/` (`src/fallout2.py`: что откуда берётся).

Что звучит:
- **музыка локаций** (`music` в `data/locations.json`): Пятнадцатая — Desert,
  карта мира — World Map, ливнёвка — Caverns, Убежище 57 — лаборатории,
  заправка и случайные встречи — рейдеры, Барстоу: трасса — Хаб, депо —
  Джанктаун, центр — Рино, святилище Ордена — чаны ВРЭ, главное меню — World;
- **оружие**: 10-мм пистолет, самопал, стрелки, турель, взмах ломом,
  попадания удара и пули, взрыв; в экшене — автомат и дробовик со своими
  выстрелами, перезарядкой и попаданиями, щелчок пустого магазина;
- **голоса** (атака / ранение / смерть): люди, гули, собака (Псина), крысы и
  крысолюды, радтараканы, панцирный жук, турель и шагоход;
- **интерфейс и мир**: начало и конец боя, открыть/закрыть контейнер,
  подобрать, щелчок меню, новый уровень, счётчик Гейгера при облучении.

Что вообще есть в Fallout 2 (для будущего): 21 трек, 1361 звук (оружие,
существа, люди, окружение — ветер, сверчки, птицы, вода; двери, лифты, казино),
речь рассказчика (114 записей) и 11 «говорящих голов».

Он обрезает тишину в начале и конце (чтобы звук совпадал с ударом),
выравнивает громкость и сжимает музыку в OGG. Какой файл каким звуком
становится — таблица `SOUNDS` в скрипте. Исходный WAV музыки в git не
кладётся, только сжатый OGG.

**Выстрелы** — пуля летит от дула к цели с коротким светящимся хвостом;
цель вздрагивает, когда пуля долетает. При промахе пуля уходит мимо.

**Обыск и тела.** Ящики, шкафы, сейфы и тела открываются окном в две
половины, как в Fallout: слева рюкзак, справа содержимое. Клик по ячейке
переносит всю стопку, правый клик — одну штуку, «Взять всё» (R) — всё сразу.
Вещи можно и класть: в любой контейнер, в том числе пустой. Убитые враги
остаются лежать, их добыча — на теле. Чужое (заначка Гены, склад банды)
считается кражей в момент, когда что-то взял; банда заметит, только если
видит вора.

**Снаряжение.** Броня надевается в слоты «Голова» и «Тело», надетое отмечено
галочкой. Новая броня сама надевается, если слот пуст. Бонусы указаны в
`data/items.json`: `armor_ac` (КБ), `ap` (ОД), `guns` (стрельба).

| Предмет | Слот | Бонус | Где взять |
|---|---|---|---|
| куртка из покрышек | тело | +10 КБ | Гена |
| бронежилет из дорожных знаков | тело | +20 КБ, −1 ОД | сейф на заправке |
| каска строителя | голова | +5 КБ | Гена |
| мотошлем | голова | +8 КБ, −5% стрельбы | вожак крысолюдов |

**Надетое видно на герое** (`tools/make_hero.py`, `src/hero_look.py`). Герой
собран слоями: основа (житель folk_j в стиле остальных жителей), броня на теле
(куртка из покрышек, бронежилет из дорожных знаков со знаком «Стоп» на груди,
балахон послушника), головной убор (каска строителя, мотошлем с визором) и
оружие в руках — лом, самопал, 10-мм пистолет, винтовка, дробовик, автомат,
те же стволы, что на иконках. У каждого оружия своя поза при ходьбе, выстрел
со вспышкой и отдачей с дымком, у лома — замах и удар с росчерком. Переоделся
или сменил оружие — спрайт меняется сразу.

**Город у трассы** — стартовая карта 96×64 клетки, собранная из набора
«wasteland town» и своих объектов: около 90 мест для обыска и 11 зданий. У
зданий все четыре стены; у домов к северу от улицы двери в южной стене, к
югу от улицы — в северной (двери смотрят на улицу). Районы:
- **запад** — въезд с трассы, остановка, отсюда старт;
- **северо-запад** — жилой квартал: дом деда, дома жителей (Марта), дворы;
- **салун «Последний глоток»** — Мо «Ведро» за стойкой, пьяница Лен;
- **рынок** — лавка Гены, прилавки, палатка брата Сайласа с бочкой
  «святой воды», доска объявлений;
- **водокачка** на северо-востоке — баки, контора, светящиеся мутанты;
- **юг у дороги** — дом Черепана без крыши, пост шерифа Брэддока, клиника
  Дока Миры, ратуша Смотрительницы Ады;
- **юго-запад** — руины склада с люком в **ливнёвку** (под городом —
  тоннели и логово крысолюдов) и кладбище с могилой пса Колбасы;
- **столовая гора** с дверью-шестернёй **Убежища 57**, часовой Дейл;
- **сквер** — высохшие деревья, скамейки, панцирный жук;
- **свалка** на юго-востоке — горы хлама, контора, лагерь рейдеров, пёс на
  цепи, лачуга Панка-одиночки.

**Новые места Пятнадцатой** (`tools/build_fifteen.py`, история — docs/story.md,
раздел 6): по трассе на восток — **старая школа «Солнечная долина»** (двор и большое
здание: классы, библиотека, кабинет директора, спортзал, где гуль-учительница мисс Лейн
сорок четыре года ведёт урок), **подвал деда** под его домом (люк открывается по записке
в терминале) и **подвал салуна** (Мо пускает, если спросить; там прячется беглянка из
культа). Интерьеры собраны из наборов бандла: стены как в RPG Maker, полы, мебель.

**Крыши, как в Fallout.** У зданий есть крыши (рубероид с вентиляцией,
ржавый профнастил, доски или бетон — по стилю стен), без надписей: где что
находится, подсказывают жители («Где тут что?» у Гены и у Ника в Бейкере;
вернуть надписи — `SHOW_ROOF_SIGNS` в `src/townmap.py`). Кто внутри — не видно. Когда герой
входит, крыша здания плавно исчезает, при выходе возвращается. Над крышей
виден верх северной стены с проёмами дверей, под ней — южный фасад. У
руин и дома Черепана крыши нет (`roof=False` в `tools/build_town.py`).

Жители иногда говорят что-нибудь вслух, когда проходишь рядом
(`data/barks.json`).

**Диалоги с портретом**: слева в окне разговора — собеседник крупно, по пояс,
на тёмном фоне с тёплой подсветкой, как «говорящие головы» Fallout.
У всех персонажей под ногами мягкая тень.

**Черепан** живёт в кирпичном доме к югу от улицы. Просит 2 химиката на мазь
для панциря и платит тоником.

Квестовых персонажей надо поискать: Блонди прячется за баком у водокачки,
Панк-одиночка сидит в лачуге на свалке. Гена подскажет, где их искать
(«Не видел тут других людей?»). Выходы из города — на западе и на юге.
Высокие объекты (стены, шкафы, палатки, баки) закрывают персонажей за собой
и перекрывают линию огня в бою.

**Бейкер — вторая глава** (`tools/build_baker.py`, `src/game/baker.py`,
сценарий — раздел 7 в [docs/story.md](docs/story.md)). Городок у трассы под
ржавым Термометром, «самым высоким градусником в мире» (стрелка застыла на
134 °F). **Ночной** и разбит на **три района** — отдельные локации, переход
по дорогам, как районы Нью-Рено:
- **трасса** (сюда приходят с карты мира): фонари и остовы машин вдоль I-15,
  блокпост культа, закусочная «Безумный грек» (Ник и пьющий брат-ключник
  Тобиас), площадь с Термометром, мотель старосты Хэтти, дом Роя, гараж;
- **миссия** «Детей Единства» за кирпичной оградой: молельня брата
  Ансельма со сканером, кельи за решёткой, трапезная, дом Ансельма, кладбище
  «вознесённых», ворота к дороге и калитка в дюны;
- **окраина**: лачуги у костров, свалка со «скупщиком» Холлисом (рация
  Анклава), водонапорная башня, бункер склада «Бейкер-7».

Побочные квесты Бейкера: **«Марла из молельни»** (Рой просит вернуть жену —
записка или [Красноречие]) и **«Книга даров»** (украсть у Ансельма книгу,
которая доказывает, что город переплатил культу, — Хэтти перестаёт платить).

**Зайзикс** (глава 3, `tools/build_zzyzx.py`, история — docs/story.md, раздел 8) —
курорт «чудо-воды» у озера Сода: бульвар с пальмами к оазису, лагерь паломников,
купальни с целебным бассейном, «Замок» Спрингера и цистерна, где Vault-Tec сто лет
назад спрятал фильтр «Чистый лист»: вода лечит от радиации — и лишает детей.
Открывается на карте после Бейкера или если пройти рядом. **Нидлс** (конец первого
акта, `tools/build_needles.py`, раздел 9) — переправа через Колорадо: пристань с паромом
Мамаши Кейт, рыбный рынок, Главная улица с салуном, лавкой и церковью, вокзал Санта-Фе,
мост с блокпостом Речной стражи, которая пропускает фургоны культа без досмотра.
Река — настоящая вода: пройти можно только по пристаням и мосткам. **Барстоу** получил пятый
район — базу морской пехоты с журналом сержанта Холта, деда Дэкса.

**Ночь и свет** (`src/lighting.py`) включаются полем `night` в карте:
синеватая темнота, тёплые круги света от фонарей, бочек с огнём, костров,
ламп, свечей и терминалов (поле `light` у объекта в `data/props.json`),
мерцание и живое пламя с искрами. Свет ламп внутри зданий через крышу не
пробивается — виден, когда герой входит и крыша исчезает.

Три пути спасения деда — любой открыт любому, а маршрут прихода даёт фору:
- **Тень** (фора — Панк): калитка в дюнах (засов поддевается ломом), ключ от
  кельи — у Искры, сестры Панка, или у пьяного Тобиаса за самогон / крышки /
  [Красноречие]. Во дворе без пропуска и балахона послушника заметят;
- **Сделка** (фора — брат Сайлас): страж у ворот пропустит с поручителем, за
  пожертвование или по слову Хэтти. Ансельма можно убедить голозаписью деда
  или [Красноречием], выменять деда на код склада или заплатить деньгами Холлиса;
- **Сталь** (фора — Лира): штурм миссии с паладинами Братства или Панком
  (союзники снимают часть охраны) — или в одиночку.

Освобождённый дед ждёт у склада и открывает его: сетчатка, голос, код.
Внизу — охранные роботы, турель и десять контейнеров ВРЭ; журнал отгрузки
заканчивает главу. Кто придёт к складу и чем всё кончится, зависит от пути.
Дальше — Зайзикс и Нидлс (третья глава).

**Карта мира** (`src/worldmap.py`) — большая карта региона 3200×2000 в духе
Fallout 2, камера следует за героем. Запад — Тихий океан и остров Санта-Каталина,
дальше Южная Калифорния, Мохаве, на востоке — река Колорадо и Невада; горы,
солёные озёра, трассы I-15, I-40, I-5, граница штатов. **Туман войны**: неизведанное
затемнено и открывается вокруг пройденного пути (сохраняется). Клик по локации —
идти к ней, клик по пустому месту — идти туда; шанс встречи растёт с длиной пути.

**Придорожные места** открываются сами, если пройти рядом, и помнят, что там
было: разбитый армейский конвой, лагерь караванщиков у Ладлоу, ферма Миллеров,
радиовышка «Голос пустоши», закусочная «Последний бургер», солёное озеро Сода
(песчаный голем), застава рейдеров на I-15 (`SPOTS` в `src/encounters.py`).

**Случайные встречи** (`src/encounters.py`) — свои в каждом регионе: в Неваде
роботы и снайперы, у реки ящеры, в Южной Калифорнии рейдеры и гули, в Мохаве
големы и жуки. Выход из локации отмечен стрелками `>>>` на краю карты. Встреча — сцена, собранная на лету из
объектов: пустыня, сухие деревья, остовы машин, иногда старая трасса. 17 видов:
крысюки, падальщики, засада рейдеров с баррикадой, жуки, дикие гули у фургона,
радтараканы, патруль культа (после Бейкера; если культ вам враг — нападает),
роботы-скелеты, снайперы на вышке, караван бродячего торговца (дробовик,
автомат, патроны, стимуляторы), почтовый робот, брошенная тележка, уникальный
трейлер Мэйбл с дневником и дробовиком. И встречи, которые не по зубам:
**песчаный голем**, **рогатый зверь**, **речные ящеры** (на востоке, у
Колорадо) и **шагающая броня**. Что выпадает, зависит от уровня героя. Уйти
можно через край карты (выходы на западе и востоке).

## Прокачка и баланс

- **Опыт** (`src/settings.py`): уровень стоит 100, 225, 350, 475… (каждый следующий на 125 дороже).
  К 5-му — 1150 опыта, к 10-му — 5400, к 15-му — 12 800, к 20-му — 23 300. Основной источник —
  квесты. Бот-игрок заканчивает Акт I на 5-м, Акт II на 9-м, основной сюжет — на 15-м.
  За врага слабее героя опыта меньше, за сильного — с надбавкой.
- **Враги по актам** (`src/balance.py`): во втором акте HP ×1,3 и +1 урона, в третьем ×1,45 и +4,
  в тайных местах ×1,55 и +5 (плюс навык и уровень).
- **Навыки** (`src/skills.py`): с каждым уровнем — повышение одного на выбор (до 60 — +10,
  60–89 — +6, 90–119 — +4, дальше +2: мастер в двух навыках — да, во всех — нет).
  - Стрельба — пистолеты, винтовки, дробовики, автоматы, Гаусс;
  - Тяжёлое оружие — пулемёты, миниган, огнемёт, ракетомёт;
  - Энергооружие — лазеры и плазма (прожигают броню);
  - Метание — ножи и копья в руку, точность гранат;
  - Рукопашная — нож, мачете, топор, кувалда, силовой кулак;
  - Медицина, Наука (взлом), Красноречие, Выживание.
- **Оружие** (`src/weapons.py`): 30 видов в пяти классах, у каждого порог навыка. Ниже порога —
  −2% к попаданию за каждое недостающее очко, очередью не выстрелить, тяжёлое — ещё +1 ОД.
  Мощный ствол можно снять с врага хоть в первом акте (у охранного робота — лазерный пистолет,
  у солдата Анклава — плазма, у супермутанта — пулемёт), но толк от него — после прокачки.
  Редкое падает с шансом (`roll_loot`).
- **Легенды** — по одной на всю пустошь, о каждой ходят слухи в барах:
  винтовка Гаусса («Арес»), миниган «Мамочка» (супермутантка в тоннелях под Стрипом),
  дробовик «Красотка» (сейф мэра Джанктауна), лазер «Звездочёт» (ядро «Новы»),
  супер-кувалда (грот Каталины).
- **Броня**: от куртки из покрышек до улучшенной силовой брони Анклава. Тяжёлая — с уровня
  (металлическая с 5-го, боевая с 8-го), силовая — ещё и после голозаписи «Курс оператора СБ»
  (Форт Сёрчлайта, «Посейдон-7»). У хорошей брони кроме КБ есть «гашение» — минус N урона с
  каждого попадания.
- **Гранаты**: обычная, коктейль Молотова, плазменная, импульсная (ЭМИ: роботам — смерть).
- **Деньги**: за выполненное городское/побочное задание — 60/150/200/250 крышек по актам.
  Тратить есть на что: патроны пачками, броня, стволы и книги навыков (+5–6 к навыку,
  300–550 крышек, по одной у торговцев второго и третьего актов).
- **Перки** (`src/perks.py`) — только на чётных уровнях, выбор из трёх.
  Сильные открываются позже: «В упор» и «Автоматчик» с 4-го, «Бронебой» и
  «Жизнелюб» с 6-го, «Снайпер» с 8-го (нужен «Глаз-алмаз»). «Твёрдая рука» помогает
  и стрельбе, и тяжёлому, и энергооружию.
- **Уровень врага** виден в подсказке над ним. На 2+ уровня сильнее героя —
  «опасен», на 4+ — «смертельно опасен».

## Набор «wasteland town» и карта города

Исходники — пять страниц 768×768 в папке `wasteland town/`. Нарезка:

```
.venv/bin/python tools/slice_town.py    # -> assets/town/ground/, assets/town/props/
.venv/bin/python tools/build_town.py    # -> data/maps/town.json
```

- Страница 1 режется по координатам: клетки земли 48×48 (асфальт,
  разметка, гравий), стены, заборы, дома, пятна земли. Боковых стен
  (с севера на юг) в наборе нет — скрипт собирает их из фасадов: сверху
  верх стены, у южного конца торец. Куски стыкуются в сплошную стену.
- Страницы 2–5 режутся автоматически по прозрачности: мебель, хлам, бочки,
  палатки, знаки, трава. Получается 341 объект.
- В `data/props.json` у каждого объекта: картинка, масштаб (набор нарисован
  в разных масштабах), пятно на земле в клетках, проходимость, закрывает ли
  обзор, что можно найти при обыске. Там же таблицы добычи.
- Карта города собирается скриптом по районам: дороги, здания, дворы, потом
  объекты и мелочи. Скрипт не ставит объект, если тот отрезал бы проход,
  и проверяет, что все NPC, враги, предметы и выходы достижимы. Случайность
  фиксирована, так что карта каждый раз одна и та же. Чтобы поменять город,
  правьте районы в `tools/build_town.py` и перезапускайте его.
- Подземелья (`tools/build_underground.py`) строятся так же, но из «скалы»:
  код земли `x` — толща стены, над полом у неё рисуется лицевая стена (стиль
  карты: `vault` — стальные панели с полосой Vault-Tec, `drain` — бетонные
  кольца с тиной). Полы: `m` — стальные плиты, `w` — мокрый бетон. Под
  землёй темно — светло только вокруг героя (`dark` в карте).
- Переходы между картами — порталы (`portals` в карте: клетки, куда ведут,
  где появиться). Гермодвери (`gates`) открываются ключ-картой или флагом
  с терминала.
- Земля: асфальт и гравий — из набора, а обычная земля генерируется
  бесшовным пиксельным шумом в цветах набора, с пятнами светлее и темнее.
- Здание в генераторе: `building(x, y, ширина, высота, стиль, south=..., west=..., east=...)`,
  стили `brick`, `concrete`, `metal`, `planks`; ширина чётная (фасады по 2 клетки).

## Сборка exe

Игра собирается в один исполняемый файл PyInstaller'ом (`WastelandReclaimer.spec`).
В файл попадают только `assets/` и `data/`, шрифты — внутри, так что
кириллица есть и там, где DejaVu не установлен. Сохранения игра пишет в
`saves/` рядом с exe, ошибки — в `crash.log` там же.

**Windows (.exe)** собирается на GitHub: вкладка **Actions → «Сборка exe для
Windows» → Run workflow**. Через несколько минут внизу страницы запуска, в
Artifacts, появится `WastelandReclaimer-windows` с exe внутри. Если поставить
тег (`git tag v0.1 && git push --tags`), exe ещё и прикрепится к релизу.
Собрать .exe на Linux нельзя: PyInstaller собирает только под ту систему, на
которой запущен.

**Linux** — локально:

```
.venv/bin/pip install pyinstaller
.venv/bin/pyinstaller WastelandReclaimer.spec     # -> dist/WastelandReclaimer
dist/WastelandReclaimer --smoke                   # проверка: город, кадры, сохранение
```

### Бот-игрок и придирчивый критик

```
.venv/bin/python tools/playthrough.py                # вся игра: акты I–III, тайные места, финал
.venv/bin/python tools/playthrough.py act1 act2      # только эти этапы

```

Бот проходит игру по-честному: без бессмертия, сам дерётся (выбирает ствол по шансу попасть,
целится в оптику роботов, кидает ЭМИ, лечится), торгует (продаёт хлам, покупает патроны,
броню, стволы и книги), читает найденные письма, взламывает терминалы по подсказкам
совпадения, ищет дорогу через двери и обходит запертые. На каждом этапе — строка отчёта
(уровень, HP, крышки, патроны, лечение, бои), в конце — проблемы и «отзыв придирчивого
игрока»: слишком долгие и слишком лёгкие бои, «чуть не умер», лишние деньги и лечилки,
жители-манекены.

## Спрайты персонажей

Исходные листы лежат в `npc/`. Формат: 192×192, сетка 4×4 кадра по 48×48.
Строки: 0 — спиной (вверх), 1 — вправо, 2 — лицом (вниз), 3 — влево.
Столбцы — фазы шага.

Особые листы описаны в `SPECIAL` в `tools/slice_sprites.py`: пёс `npc/dog.png`
(512×512, клетки 128×128, строки вниз/вправо/вверх/влево) режется в
`assets/sprites/dog/` уже в игровом размере (файл-метка `native` — без
увеличения).

Листы «вразброс» из интернета (`LOOSE` там же): фон-шахматка прозрачности
вырезается, кадры находятся как отдельные фигуры. `npc/rat_boss.png` (ящер,
13 кадров) — крысюк, `assets/sprites/rat/`; `npc/warrior.png` (мех с
пилотом, один кадр) — шагоход Анклава, `assets/sprites/mech/`.

Часть врагов нарисована поверх уже нарезанных персонажей —
`tools/make_variants.py` (после нарезки; `preview` — лист-превью):
рейдер — из Панка (красный ирокез, бандана, наплечник с шипами), бандит
Бензо-банды — из героя (противогаз, промасленная кожанка с жёлтой полосой),
Шрам — из Панка (бритый, шрам через лицо, светящийся глаз, два наплечника),
панцирный жук — из пса (хитин, надкрылья, усики, жвалы, лишние лапы).

Нарезка в кадры игры:

```
.venv/bin/python tools/slice_sprites.py
```

Кадры попадают в `assets/sprites/<id>/{down,left,right,up}/0..3.png`, игра
увеличивает их в 2 раза без сглаживания. Кто есть кто — в словаре `SHEETS`
в начале скрипта:

| Лист | id | Кто |
|---|---|---|
| hero_01 | player | главный герой |
| npc_02_office_mutant | gena | Ржавый Гена |
| npc_03_blondie | blondie | Блонди (квестовый) |
| npc_04_raider | loner | Панк-одиночка (квестовый) |
| npc_05_ratman | ratman | крысолюд (враг, ходит стаей) |
| npc_05_ratman_boss | ratman_boss | вожак крысолюдов |
| npc_06_mutant | rad_mutant | светящийся мутант (медленный) |
| npc_07_mutant_turtle | turtle | Черепан, мирный мутант-черепаха (квест) |

**Боевые анимации героя** — удар ломом и выстрел по 3 кадра на каждую
сторону — дорисованы поверх нарезанных кадров скриптом:

```
.venv/bin/python tools/make_hero_anims.py   # -> assets/sprites/player/melee/, shoot/
```

Если перерисовать героя (новый `hero_01.png`), скрипт нужно перезапустить
после `slice_sprites.py`. Реакции на попадание (отброс и красная вспышка) и
уворот при промахе врага игра строит сама для всех персонажей из их стоячего
кадра. Свои кадры можно положить в `assets/sprites/<id>/melee|shoot/<сторона>/`.

Новый персонаж: положить лист в `npc/`, добавить строку в `SHEETS`,
перезапустить скрипт. Враги описываются в `data/enemies.json`, на карте их
обозначает буква из `ENEMY_TILES` в `src/tilemap.py`: `k` — крысолюд,
`K` — вожак, `z` — светящийся мутант, `m` — мутант-падальщик, `r` — крысюк,
`R` — рейдер, `B` — жук, `g` — бандит, `S` — Шрам. Это для текстовых карт;
в городе враги расставляются в `tools/build_town.py`.

У остальных (рейдеры, бандиты, Шрам, жук, крысюки, робот) пока
плейсхолдеры. Для них подходит та же схема: `assets/sprites/<id>/`.
Иконки предметов — `assets/items/*.png`. Тайлы и фон текстовых карт (заправка,
встречи) — `assets/tiles/*.png`, `assets/bg/layer0..2.png`.

## Бандл Cute SCKR: наборы для всех городов

Купленный бандл (480+ наборов: пустыня, оазисы, порты, больницы, лаборатории,
бункеры, военные базы, казино, фермы, киберпанк…) лежит **вне git** в
`../tilesets_sckr/` — лицензия запрещает распространять исходники. Скачать и
распаковать:

```
# скачать всю библиотеку покупок itch.io (ключ: itch.io/user/settings/api-keys)
python3 -m venv .itchdl && .itchdl/bin/pip install itch-dl
.itchdl/bin/itch-dl https://itch.io/my-purchases --api-key КЛЮЧ --download-to tilesets_sckr
tilesets_sckr/extract.sh        # распаковка (unrar от RarLab — ../.tools/rar/unrar)
```

В игру нарезается только то, что нужно городу:

```
.venv/bin/python tools/packs.py find desert                 # какие наборы есть по слову
.venv/bin/python tools/packs.py slice <набор> <короткое имя>  # -> assets/packs/<имя>/
```

В git из `assets/packs` попадает только то, что реально стоит на картах (страницы,
объекты, полы и стены, на которые ссылаются `data/maps/*.json` и `data/props/*.json`);
остальная нарезка лежит на диске и в `.gitignore`. Перед коммитом:

```
.venv/bin/python tools/packs.py sync-git
```

- **объекты** со страниц с прозрачным фоном вырезаются по альфе (дома, мебель, машины);
- **страницы целиком** копируются: многие — готовые композиции (озеро с берегом и
  лодками, мощёная дорожка, дом на песке), из них берётся любой кусок по клеткам 48 —
  картинка `pk:<набор>/p<N>/<x>,<y>,<ш>,<в>`;
- **полы A2** — бесшовные заливки 48×48 (песок, плитка, доски, металл);
- **стены A4** — как в RPG Maker: тёмный верх с окантовкой и фасад в 2 клетки.
- Сводки для подбора — `../tilesets_sckr/_catalog/<имя>_p<N>.png` (страница с сеткой
  и номерами клеток), `_floor.png`, `_walls.png`.

Карты получают свои коды земли: `"floors"` (пол из набора) и `"walls"` (стена A4,
непроходима), `_` — чёрная пустота за стенами интерьера. Конструктор больших городов —
`tools/citykit.py`: районы, интерьеры с дверями, этажи и подвалы с лестницами, штампы
композиций (вода в них сама непроходима), объекты наборов в `data/props/<город>.json`.

Иконки предметов (`tools/make_item_icons.py`) — из наборов иконок выживания:
инструменты, еда, вода, медицина, снаряжение; добавлены консервы, противогаз,
батарейки, изолента, фонарик, рация, бинокль, верёвка, порох и др. — они попадаются
при обыске.

## Набор «War ruins» и листы персонажей из интернета

**War ruins** (comshadow, https://comshadow.itch.io/post-apocalyptic-war-ruins-tileset) —
27 страниц 768×768 в папке `War ruins/`: лачуги, палатки, бункеры, вышки,
машины, трейлеры, мешки с песком, деревья, мебель, плитки земли.

```
.venv/bin/python tools/slice_ruins.py [--catalog]   # -> assets/ruins/props/r<стр>_<номер>.png, ground/, index.json
.venv/bin/python tools/make_props.py                # имена объектов (r_shack, r_bunker…) -> data/props.json
```

Объекты ищутся по альфе, повторы между страницами сохраняются один раз.
`--catalog` рисует сводки страниц с номерами. Какие объекты используются и
под какими именами — таблица `RUINS` в `tools/make_props.py`. У сухой травы
из набора под картинкой квадрат песка, поэтому на картах её нет.

**Листы персонажей из интернета** лежат в `npc/raw/` как скачаны (jpg, gif,
листы RPG Maker). Конвертер приводит их к формату игры:

```
.venv/bin/python tools/import_sheets.py [--preview]   # -> npc/<id>.png (4×4: вверх, вправо, вниз, влево)
.venv/bin/python tools/slice_sprites.py              # -> assets/sprites/<id>/
```

Конвертер убирает белый или зелёный фон и режет кадры по сетке, даже если
они стоят вплотную. Ещё он умеет перекрашивать (повязка солдата, белый
балахон Ансельма). Как читать каждый лист — `SOURCES` в скрипте, рост в
игре — `IMPORTED` в `tools/slice_sprites.py`. Готово 33 персонажа: дед
Эймос, культист, детектив, целитель, бармен, охранник, солдат, жители,
охранный робот, робот-скелет, шагающая броня, песчаный голем, речной ящер,
зверь и другие. У картинок из интернета неизвестные лицензии: для личной
игры это нормально, перед публикацией их нужно проверить или заменить.

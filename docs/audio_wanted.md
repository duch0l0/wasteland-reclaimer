# Что нужно найти: музыка и звуки

Куда класть: `incoming_audio/<папка>/` (папки ниже). Формат любой (mp3/wav/ogg/flac) — обработаю сам:
обрежу тишину, выровняю громкость, сделаю бесшовную петлю и ogg.

**Лицензия — только CC0 или CC-BY.** Не брать: NC (некоммерческие), ND, «бесплатно для личного
использования», «все права защищены», YouTube Audio Library без отдельной лицензии, каверы известных песен.
Рядом с каждым файлом положи `<имя>.txt` с одной строкой — ссылкой на страницу файла (не на сайт целиком).
Лицензию по ссылке проверю сам и впишу в CREDITS_AUDIO.md.

Где искать: Kevin MacLeod / incompetech.com (CC-BY), Alexander Nakarada / serpentsoundstudios.com (CC-BY),
freemusicarchive.org (фильтр CC0/CC-BY), opengameart.org (фильтр CC0/CC-BY), freesound.org (фильтр CC0),
Kenney.nl (CC0), Eric Matyas / soundimage.org (своя бесплатная лицензия с указанием автора — подходит).

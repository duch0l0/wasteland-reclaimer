# План: квесты — все работают, связаны и интересны

Статус: [ ] — не начато, [~] — в работе, [x] — в игре и подтверждено ботом/тестом.
Инструмент: `tools/quest_audit.py` — статический разбор всех 83 квестов (кто выдаёт, пути к
выполнению, закрыт ли путь навыком, награда, связи с другими квестами, «эхо» — реакция мира).
Бот: `tools/playthrough.py` + `tools/bot_sides.py`.

## Приёмка блока

1. **Бот проходит все 83 квеста** (главные и побочные) хотя бы одной сборкой; каждый квест —
   хотя бы одним путём без редкого навыка. Квесты с выбором — тест на каждую развилку.
2. **Баланс «побочки — путь к силе»** (память: difficulty stance):
   - только сюжет (`--nosides`) — бот гибнет или застревает не позже середины акта III;
   - ~70% побочек — бот проходит до концовки; уровень, броня, оружие к каждому акту по таблице ниже;
   - враги с каждым городом крепче (`src/balance.py` ENEMY_SCALE, `data/squads.json`) — не трогаем
     вниз; если побочки не дают нужной силы — поднимаем награды побочек, а не режем врагов.
3. **Связи:** ни одного «изолированного» квеста — каждый либо меняет другой квест, либо главный сюжет,
   либо мир (барки, слухи, перемены города, эпилог). `quest_audit.py`: «изолирован» и «мир не замечает» → 0.
4. **Интерес:** у каждого квеста есть выбор с последствием или неожиданный поворот; нет квестов
   «принеси N штук» без истории. Награды растут по актам.

## Целевая сила героя по актам (с ~70% побочек)

    акт II (Убежище 4)  11-12    металлическая 26        боевой дробовик, штурмовая винтовка
    акт III (Вегас)     15-16    боевая/рейнджер 28-30   снайперская, энергооружие
    финал              17-18     силовая 32-36           Гаусс / плазма

## Этапы

- [ ] **Q0. Замер.** Полный прогон и `--nosides`, `quest_audit.py` — исходная точка (ниже).
- [ ] **Q1. Бот проходит всё.** Сценарии для восьми нетронутых квестов (3.1 из review_plan) и
      для тех, что бот бросает; честные причины в отчёте (3.2).
- [ ] **Q2. Второй путь без навыка** (3.3): Термометр, Улыбка папы, Последняя стена, Лёгкие Шпоры,
      Монета судьи, Жёлтые треугольники, Отчаянный, Колокольня, Вода для Арадеша — у каждого путь
      через предмет/спутника/действие или явная подсказка, где взять навык.
- [ ] **Q3. Связи и эхо.** Для каждого «изолированного» квеста — хотя бы одна нить: последствие в
      другом квесте, реплика в другом городе, строка эпилога.
- [ ] **Q4. Интерес и награды.** Пройти слабые квесты акта I (Пёс на цепи, Крысы, Колбаса, Зачистка
      Барстоу, Марла, Сестра Панка): выбор, поворот, награда по таблице силы.
- [ ] **Q6. Квестодатель виден неброско** (решение автора 23.10, по-фоллаутовски): без значков над
      головой; при наведении — имя и строка «◆ есть дело» (новое задание) / «◆ ждёт ответа» (можно
      сдать) жёлтым, тёплый контур вместо белого; в журнале у стадии — кто и где. Источник истины —
      quest_audit (кто выдаёт) + условия start/options диалога, а не ручной список.
- [ ] **Q7. Решения и развилки** (просьба автора 23.10). Каждый выбор где-то отзывается:
      а) `tools/quest_audit.py --choices` — узлы, где реплики ставят разные флаги (развилка), и для
         каждой ветки — кто её читает (другие диалоги, перемены города, барки, эпилог); ветка без
         отклика = «пустой выбор»;
      б) три ветки каждого акта и три концовки: бот с ключом `--path A|B|C` проходит каждую, в отчёте —
         какие флаги ветки поставлены, что изменилось в мире, какая концовка и какие слайды эпилога;
      в) тест на каждую ветку акта: последствие видно в следующем акте.
- [ ] **Q5. Баланс-замер.** Бот с побочками и без, 2 сборки × 2 сида; таблица уровня/брони/оружия
      по актам; приёмка п.2.

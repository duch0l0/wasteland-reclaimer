# Бейкер — расстановка (docs/furnish/logic.md)

Город ночной, три уличные карты + интерьеры. Уличные карты — ×1.56 по стороне (как Пятнадцатая), поштучно.

Правки второго захода (замечания Claude): лобби мотеля — стойка с ключницей, уголок с диваном и креслами на ковре вокруг столика, автоматы у стены, свободный проход к лестнице; дом Роя — полка к северной стене, без лишнего; гараж — ворота боксов к трассе, без дерева внутри, инструмент по одному у машины; площадь — скамьи рядами к Термометру, бак за площадью, без машин на брусчатке; указатель «МОТЕЛЬ →» на столбе у обочины.

Сюжетные места: Лира (41,52) у костра караванщиков, Марла (16,57) в доме Роя, Искра (40,20) у Термометра; со второго этажа мотеля — в холл (79,17).

Свет: у каждого пятна — видимый источник; «потолочный» свет карты движок дорисовывает лампой на шнуре (src/townmap.py, _hang_pendants).

## Исходное состояние (2026-10-17)
- `src/audio.py` + `src/fallout2.py`: 45 ключей эффектов (`SFX`) и 10 ключей музыки (`MUSIC`).
  Игра берёт звук из установленного Fallout 2 игрока (кэш `f2cache/`). Для релиза так оставлять
  можно только как необязательный бонус; своего набора нет: `assets/sounds` — 3 файла (hit, melee, shot),
  `assets/music` — пара треков.
- Нет: шагов, ambient по локациям, интерфейсных звуков (кроме button/pickup), звуков дверей по типам,
  звуков терминалов, критов, брони, взрывов по типам, погоды, ночи, голосов толпы.
- Правило: в репозиторий и в exe попадают ТОЛЬКО свободные файлы. Fallout 2 — только из копии игрока.

## Шаги
1. **Аудит событий.** Скриптом собрать все `audio.play("…")` и `play_music("…")`, сопоставить с `SFX`/`MUSIC`,
   составить таблицу `docs/audio_events.md`: событие → есть ли свой звук → чем закрыть. Добавить недостающие
   события в код (шаги по покрытию: песок/плитка/металл/вода; двери; терминал; крит; промах; броня; лечение;
   радиация; торговля; диалог; квест выполнен; смерть героя).
2. **Правила лицензий.** Брать только CC0 и CC-BY (CC-BY — с атрибуцией). Не брать NC, ND, «для личного
   пользования». Каждому файлу — запись в `CREDITS_AUDIO.md`: файл, автор, ссылка, лицензия. Страницу файла
   проверять отдельно, не верить описанию сайта.
3. **Источники:** OpenGameArt (CC0-паки), Kenney (CC0), Freesound (фильтр CC0), itch.io (CC0-паки),
   музыка: Incompetech/Kevin MacLeod (CC-BY), Free Music Archive (CC0/CC-BY), Pixabay (своя свободная лицензия:
   читать условия), Eric Skiff, Alexander Nakarada (CC-BY).
4. **Эффекты:** оружие (по типам: самопал, пистолет, дробовик, винтовка, пулемёт, энергия, плазма), удары,
   попадания по телу/броне, крики и смерть (человек, крыса, жук, гуль, робот, собака, радскорпион),
   шаги, двери, ящики, терминалы, интерфейс, левел-ап, счётчик Гейгера. Недостающие простые звуки (клики,
   писки терминалов, щелчки замков, гудение) сгенерировать кодом (numpy → wav), лицензия — наша.
5. **Ambient (петли, 20–40 с, бесшовные):** ветер пустыни, ночь/сверчки, ливнёвка (капли, эхо), пещера,
   убежище (вентиляция, лампы), Нова (гул, дроны), Вегас (неон, ветер), лагерь/костёр, город-толпа,
   интерьер (тишина + тик). Подключить к `Location.music`/новому полю `ambient` в `data/locations.json`.
6. **Музыка (8–10 треков + бой):** меню, карта мира, пустошь, города (3 настроения), пещера/убежище,
   бой (2 уровня напряжения), опасная зона, финал/титры. Те же ключи, что в `MUSIC`, чтобы код не менять;
   свои файлы идут в `assets/music/`, Fallout 2 — необязательная замена, если найден.
7. **Загрузка:** нормализовать громкость (ffmpeg loudnorm), ogg для музыки и ambient, wav/ogg коротких
   эффектов; общий размер держать до ~60 МБ. Проверка: без `fallout2_sounds` и без Fallout 2 игра звучит
   полностью; с ними — как раньше.
8. **Тесты и приёмка:** `tests/test_audio.py` — все ключи `SFX`/`MUSIC` имеют свой файл; нет ссылок на
   несуществующие файлы; в `CREDITS_AUDIO.md` есть запись для каждого файла из `assets/sounds` и `assets/music`.
   Прослушивание на слух — за пользователем: по 2–3 варианта на ключевые события, выбор за ним.
9. **Релиз:** убрать упоминание «Fallout 2» как обязательного звука из README, оставить как опцию игрока;
   обновить `CREDITS` и сборку (`WastelandReclaimer.spec`).
